# Наземная станция с окном

Ноутбук на земле: принимает находки с дрона и показывает их — кадр с рамкой
и всё, что пришло в JSON-метке (что найдено, уверенность, координаты, GPS,
время съёмки).

Протокол тот же, что у `tools/ground_server.py` и `ReliableLink.hpp` на борту,
поэтому на дроне ничего менять не надо. Запускать **что-то одно** — `viewer.py`
или `ground_server.py`: оба слушают порт 5700.

## Что нужно

Python 3 с tkinter и Pillow. На Ubuntu обычно уже стоят, иначе:

```sh
sudo apt install python3-tk python3-pil
```

## Запуск

```sh
cd ground_viewer
python3 viewer.py                         # порт 5700, всё принятое в finds_viewer/
python3 viewer.py --dir rescue_17oct      # своя папка
```

Запускать до взлёта: дрон подключается сам и сам переподключается после
обрывов. На борту в `src/main.cpp` в `GROUND_STATION_IP` должен стоять адрес
этого ноутбука (`ip -4 addr`). Если включён файрвол: `sudo ufw allow 5700/tcp`.

Показать готовые файлы без приёма по сети:

```sh
python3 viewer.py --no-listen --image find.jpg --json find.json
```

То же из окна — кнопка «Открыть файлы…»: сначала кадр, потом JSON (можно отменить).

## Проверка без дрона

`fake_drone.py` изображает борт: шлёт метку и кадр, ждёт подтверждения.

```sh
python3 viewer.py &                       # окно
python3 fake_drone.py --count 5           # пять придуманных находок
python3 fake_drone.py --image my.jpg --json my.json   # свои файлы
```

## Что в окне

- **Слева** — все находки, новые сверху. Цвет: человек — красный, задымление —
  оранжевый, маркер ArUco — синий. Если снята галочка «Сразу показывать новые»,
  непросмотренные выделены жирным. На каждую новую находку — звуковой сигнал.
- **Справа** — кадр, поля метки и сам JSON. «Открыть на карте» открывает точку
  в OpenStreetMap, «Копировать» кладёт координаты в буфер обмена. Кнопки
  неактивны, если борт прислал находку без координат (`geo_valid: false`).
- **Сверху** — есть ли связь с дроном и сколько всего находок.

## Что лежит на диске

В папке `--dir`: `events.jsonl` (метки, по одной на строку) и кадры
`<время съёмки, мкс>_<номер события>_frame.jpg`. Подтверждение дрону уходит
только после записи на диск. При следующем запуске окно открывается со всей
историей.

## Отличие от ground_server.py

Повторы отсеиваются по **содержимому** записи, а не по номеру события. На борту
номер начинается с 1 при каждом запуске программы, и `ground_server.py` после
перезапуска борта принимает новую находку №1 за повтор старой и выбрасывает её.
Здесь переотправка после обрыва (байт в байт та же) — повтор, а новая находка
с тем же номером — новая.
